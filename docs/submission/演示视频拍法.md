# 演示视频拍法（5–8 分钟 · 1080p · 普通话）

> 赛题要求：5–8 分钟 MP4、≥1080p、普通话；视频统一传 B站 / 抖音等可公开访问的平台，提交 https 链接，**不要提交百度网盘**。本文给的是可直接照做的分镜、旁白与兜底。

## 0. 先定三件事

1. **主线**：一条「诊断 → 路径 → 导师（Agent + 向量 + 多模态）→ 设置（MCP/语气）→ 工程证据」的完整链路，不按功能清单平铺。
2. **时长**：目标 6 分 30 秒，留 30 秒余量；超过 8 分钟必须剪。
3. **口径**：只演示跑通的东西。没跑通的（真机 TTS、PDF worker、浏览器 Worker 推理）要么不拍，要么在字幕里标「未验证 / 预录」。

## 1. 录制前 30 分钟清单

- [ ] `npm run dev`（或直接用线上地址），确认首页 200。
- [ ] 准备一个**演示账号**：不要用个人邮箱；注册后到「设置 → 模型供应商」保存服务端模型配置，点「测试连接」通过。
- [ ] 预热：先问导师一句无关问题，让模型与页面缓存热起来；首问通常最慢。
- [ ] 准备一份 2 页的示例讲义（Markdown 或带文本层 PDF），里面放一句独有的话，例如：「本讲义定义：红黑树是一种自平衡二叉查找树。」

  - 本地：加 `http://127.0.0.1:3210/api/mcp`，但启动 dev 时要设 `ALP_ALLOW_HTTP_PROVIDER_HOSTS=127.0.0.1:3210`。
- [ ] 浏览器 1440×900、缩放 110%，隐藏书签栏；清掉与演示无关的标签页。

- [ ] 关掉通知、微信、下载弹窗；确认屏幕上不会出现密钥、手机号、个人邮箱。

## 3. 旁白稿（可直接照念）

**0:00–0:35**
> 高校硬课里，学生最常问的不是「这题怎么做」，而是「我现在到底该学哪一步」。我们做了一条算得出、说得清、改得动的学习路径：先修图决定能不能学，Beta 后验决定先学哪个，时间预算决定这次学到哪。

**0:35–1:10**
> 先做诊断。系统按先修顺序出题，每道题都告诉你「这题预测你有多大概率做对」。答完立刻看到这个知识点的掌握度从多少变到多少，以及不确定区间。

**1:10–2:00**
> 诊断完进入路径。九十预算下排出七步；改成三十分钟，同一条算法只装得下三步，其余进入推迟；因为先修被推迟，后继会被标成阻塞，而不是硬排。页尾是输入指纹和路径指纹，同一份输入永远得到同一条路径。

**2:00–3:00**
> 导师不是普通问答。服务端模式下打开智能体，模型会在有界循环里决定调用哪个工具：先列学科，再规划路径，最后用工具结果收口。右侧是每一步的轨迹；工具失败会自动退回普通流式问答，不会卡住。

**3:00–4:10**
> 上传自己的讲义后，回答优先引用你的资料，引用可以逐字核对。问一个教材里没有的域外问题，它会明确说没有依据，而不是拿维基百科或者佛经来凑。

**4:10–5:10**
> 图片和语音都是真输入。粘贴一张题目截图，不输入文字也能问；回答会先把图中文字转写出来，再解答。语音只负责把问题填进输入框，不会自动发送。

**5:10–5:40**
> 语气可以切换。陪伴模式会先把情绪接住，再给下一步；严格模式会直接指出问题、给训练计划。两种都遵守同一套回答结构。

**5:40–6:15**
> MCP 服务器由用户自己加：填地址、启用、测试连接，鉴权头加密保存，界面只回掩码。模型只能调用白名单里的只读工具，地址不能由模型决定。

**6:15–6:55**
> 工程侧，98 个测试文件、2032 条用例、类型检查与生产构建全绿；检索评测和导师 rubric 都在 verify 里。没有跑通的真机 TTS、PDF worker、浏览器推理，我们写在 docs/limits.md，不写成已实现。

## 4. 失败兜底的三条纪律

1. **不伪造**：模型挂了就展示错误与降级，不拿 mock 冒充真机；必须用预录片段时，字幕打「预录」。
2. **不静默换路径**：图片不被支持时，界面会要求「改为文字提问」；视频里也照实说，不剪掉。
3. **不暴露隐私**：演示账号用专用邮箱；录制前检查地址栏、设置页掩码、终端输出，确保没有密钥、手机号、个人邮箱。

## 5. 剪辑与上传

- 剪掉等待超过 3 秒的空转；保留一次真实的「思考中 → 工具轨迹 → 回答」过程，这是 Agent 的证据。
- 关键数字（2032、10 页面 + 18 API、OOD empty 1.000）加角标，角标口径与 README 一致。
- 导出 MP4（H.264、1080p、30fps、AAC 192kbps），文件名 `chuanzhibei-2026-demo.mp4`。
- 上传 B站：标题「可解释的自适应学习路径｜2026 传智杯 AI WEB」，简介写演示账号与仓库地址，分区选「校园学习 / 科技」，公开可见。
- 用无痕窗口打开视频链接，确认未登录也能播放；提交 https 链接，不提交网盘。

## 6. 不要做的事

- 不要用「自主 Agent」「多模态理解」「向量检索带来提升」这类超出证据的说法；说「有界工具循环」「图片 + 语音输入」「已搭 pgvector，向量收益尚未用 hard 集证明」。
- 不要把 50 条检索评测的 1.000 说成「检索效果很好」——它已饱和，只证明基础检索没坏。
- 不要在视频里现场赌 TTS 出声或 PDF worker；没验证就先不拍，或拍降级路径。
- 不要出现百度网盘链接、个人手机号、真实邮箱、任何 API key。
