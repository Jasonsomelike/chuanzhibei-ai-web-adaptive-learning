**总体口径**：35% 的六个子项都有可指到的代码与可跑的命令，但「有实现」不等于「拿满」——上表的缺口就是扣分点。答辩时建议按「已实现 + 证据命令 + 明确缺口」三句话讲，不把 mock 结果说成真机结果，不把「有界工具循环」说成「自主 Agent」，不把「图片 + 语音输入」说成「多模态理解」，也不把 50 条饱和评测说成「向量有效」。
