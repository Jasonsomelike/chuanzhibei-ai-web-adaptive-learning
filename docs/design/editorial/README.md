# 编辑式学习工作台 · 设计基准

2026-11-10。用户选择第二张「学习地图」的布局与橄榄配色作为默认；另外两种布局作为设置选项，布局与主题独立。

本目录为先行生成并检查的设计图，不是已完成界面的截图。应用数据、先修边与学习证据以真实程序结果为准；图中「布局示意」、样例状态、模型生成的错字或错误选中项不进入正式界面。

## 已确认的产品要求

- 全部十页重新规划；电脑为主，手机完整可用。日常学习优先，做好功能与体验自然支撑比赛展示。
- 温暖、有编辑感；以留白、对齐、字号、行距和分隔线建立层次，减少卡片堆叠与杂糅说明。
- 图谱成为学习主导航：看先修、选知识点、开始学习；图谱与学习清单双向联动。
- 设置直接可达；加载学习记录时保持布局稳定，减少突兀位移，支持减少动态效果。
- 导师以对话为主；侧边管理会话，教材与引用按需展开。
- 完整历史问答、引用原文、练习与结果、问题图片跨设备恢复；支持搜索、重命名、置顶、归档、删除和从某轮问答处分支，原会话不变。
- 会话永久存档与模型上下文预算分开；不得以截断模型上下文为由丢弃历史。旧版本已经丢弃的内容不能补造。
- 保留项目名称「自适应学习路径」、真实业务能力、算法、证据与用户数据；不使用另一比赛项目的名称作为品牌。

## 设计系统

默认色板：暖白 `#fafaf7`、浅燕麦导航 `#ecede4`、石墨文字 `#252a25`、橄榄强调 `#46513e`、琥珀焦点；证据状态同时用文字/形状表达。保留其他配色与明暗模式，布局切换不改配色，也不重置课程、知识点和会话。

桌面地图导航约 92px；导览导航约 204px；章节模式改为顶栏并在图谱中显示章节目录。手机统一使用可触达的五入口与直接设置入口。正文/控件 14–16px，行高约 1.6–1.8；衬线字体只用于少量标题，不用于长段说明与控件。普通列表共享一个表面，细线分行；仅真正独立的任务、输入和弹层使用边界。

图谱圆形锚点、标签与连线采用实际 React Flow 图结构，图谱不是背景图片。测试样例使用当前课程的合法目标与预算，校验节点/清单/详情的一致性和原有黄金指纹。

## 组件调研与取舍

参考 [Radix Primitives](https://github.com/radix-ui/primitives)、[shadcn/ui](https://github.com/shadcn-ui/ui)、[Base UI](https://github.com/mui/base-ui)、[React Aria](https://github.com/adobe/react-spectrum)。现有项目已使用 Radix，继续用于焦点管理、抽屉和弹层；通过项目自己的布局与排版实现已选择设计，不叠加整套预设皮肤。

图标比较 [Lucide](https://github.com/lucide-icons/lucide) 与 [Phosphor](https://github.com/phosphor-icons/react)；设计图的细描边圆角图标优先匹配 Lucide 的独立组件。已有品牌标记继续作为项目资产，不把整张设计图当作交互界面。

## 生图提示词与执行方式

使用内置 image_gen，无外部 API 凭据。提示词模板为 UI Screenshot System；全部生成均附带用户选中的第二张图作为真实视觉参考，其余初始截图仅用于功能内容参考。

共同提示词：生成一张完整、可实施的中文学习产品界面；桌面目标 1440×1024，手机 390×844；无浏览器/设备外壳；严格沿用暖白、燕麦、橄榄、石墨、琥珀；少量衬线标题与清晰无衬线正文；使用留白、对齐与细线分层；不增加营销标语、虚构掌握度、统计卡片、嵌套卡片、无关功能或装饰性图谱。当前日期 2026-11-10。保留真实课程名称与先修关系，示例标注「布局示意」。

各页提示词分别使用上表的功能、构图和页面目标。设置页明确要求三个布局缩略图共享同一配色；两种可选图谱布局明确要求只继承结构、不继承初始红/蓝配色。导师页要求完整会话列表、分支来源与按需资料，手机导师则使用关闭状态的会话抽屉和固定输入区。手机图谱要求保留可读的焦点邻域并能切换清单，不把桌面全图直接缩小。

## 实施与验收约束

先完成全页设计，再编码。实现分为设计系统与三种布局、图谱与全页应用、持久会话与分支、完整验收四部分；每轮检查后提交推送。保护既有未提交作品材料，`AGENTS.md` 只留本地。

验收包括：概念图与浏览器同状态比较；全部页面桌面/手机、三种布局与主题独立切换；设置直接到达；图谱焦点与清单/详情联动；真实答题与路径不变；会话新建/搜索/改名/置顶/归档/删除/分支/跨设备恢复（含图片、引用和练习）；账号隔离、取消/失败与并发保护；加载无跳动、键盘与减少动态效果；typecheck、lint、tests、build、E2E、密钥与数据检查。
