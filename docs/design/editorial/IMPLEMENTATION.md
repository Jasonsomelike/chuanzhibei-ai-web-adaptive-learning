## 图谱导航与三种排列

- 地图：主画布、右侧学习顺序、底部详情；导览：画布和详情分栏、底部横向顺序；章节：课程目录、纵向画布、右侧详情与顺序。
- 使用真实先修边、路径与作答证据；优先呈现选中点附近的应用与同章分支，全科与搜索保留全部知识点。横向长链折为紧凑列，窄画布聚焦选中点，保持文字可读。
- 节点、搜索、键盘、先修入口和清单双向联动；目标范围、预算与选中点按课程保存，设置往返可恢复。换号清理视图存档。
- 保留手动改序、移除、约束检查、预算反事实、章节选择和可复现指纹，移至清晰的编辑与详情入口。
- 保留全局 Ctrl K 搜索；系统及用户减少动效偏好均作用于图谱、滚动与保存反馈。
