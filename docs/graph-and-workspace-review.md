## 学习图谱

- 使用 Dagre 按真实先修边分层，水平、章节和手机布局均不折叠先修层级。排序稳定，筛选只改变可见集，不改学习证据。
- 节点固定尺寸与实际 CSS 一致；连接点位于完整节点边缘。正交可见性网格绕开节点外扩 12px 的矩形，包含跨层长边。使用线段而非圆角曲线，避免拐角切入文字框。
- 当前路径展示安排、所需先修及少量邻近节点；默认取景保证当前区域可读，完整取景按钮查看所有可见节点。全科模式保留缩放平移。
- 节点标注计划序号，未知状态以图例解释；清单、搜索、图谱选择及学习入口共用知识点 ID。拖动尺寸时等待 160ms 稳定后取景。
- 9 门课程 × 3 种布局检查矩形重叠、真实边数量、连线穿越和确定性。浏览器进一步检查缩放后的 SVG 路径与实际 DOM 框。

## 课程导师

- `react-resizable-panels` 提供可访问分隔条。历史栏默认 292px、范围 240–480px；聊天区域至少 600px。支持拖动、方向键和双击重置。
- 宽度只在用户完成操作时持久化。窄屏不覆盖偏好，恢复宽屏时还原。对话和输入组件在切换尺寸时保持挂载。
- 视窗小于 1024px 或工作区不足 860px 使用历史抽屉；保留教材引用抽屉。修复六个手机导航入口换行遮挡发送按钮。
- 空历史不再重复显示“最近 0”，输入框随内容增长，上限 180px。正文保留原有最大阅读行宽。
