# 自适应学习路径 V3 实施与验收

设计依据为用户提供的《官方推荐对照_UI视觉改造与Canvas应用手册》和《自适应学习路径_V3交互原型》，从 `D:/夸克` 读取，基于 `2fe08f1` 分三轮实施。原型中的课程进度、题目和回复是模拟数据，正式页面继续使用当前学情、题库与导师接口。

## 设计系统与适配

- 主区以纸张表面、克制的阴影和 16–18px 圆角区分工作区域。暖砂浅色的页面底、纸面、正文与主色对应原型的 `#f7f4ef`、`#fffefa`、`#292721`、`#a14c28`；所有其他配色继续由既有主题变量驱动。
- 标题 26–30px，主任务 27–36px，正文 14–16px，说明 12px；主间距 22–32px，触控入口至少 44px。
- 首页采用约 60:40 主任务与进度布局。Canvas 只有固定关系纹样，不承担业务图谱、文字、输入与点击。
- 桌面保留现有顶栏，而非替换成原型的 238px 侧栏；这是手册明确允许的适配。手机底部提供概览、诊断、路径、导师四个真实路由，顶部保留搜索、更多工具与账号入口。
- 继续复用现有 Radix Dialog/Tooltip、命令菜单、GSAP、React Flow；没有为了组件名称安装第二套主题或动画框架。新画布是原生 Canvas 2D。

## 原型与实际渲染对照

本轮对照同时查看了原型和浏览器截图。截图由 Playwright Chromium 在 1440×960 与 390×960 采集，启用减少动态效果；ego 能读取并操作页面，但截图接口持续报告窗口最小化、视口模拟尺寸也不一致，因此指定尺寸截图采用既有 Playwright。

| 对照点 | 原型 | 实际与处理 |
| --- | --- | --- |
| 主构图 | 主任务约六成、课程进度约四成 | 保持同类比例与第一视口主操作；保留实际顶栏 |
| 色彩与表面 | 暖纸色、轻阴影、柔和边线 | 映射暖砂主题变量；深色及另外四套配色沿用各自语义变量 |
| 文字层级 | 课程任务大标题、较小说明与元信息 | 根据真实知识点名称自然换行；没有照搬“栈与队列”模拟任务 |
| 任务点缀 | 低对比度关系线和少量节点 | 原生 Canvas，前景真实 HTML 按钮；手机降低纹样不透明度 |
| 统计 | 模拟 12/40、3 项、4.3h | 新用户真实 0/40；只显示实有测评、达标与复习记录；不生成学习时长 |
| 手机 | 先任务、后进度，底部四入口 | 同样顺序；正文与输入保留底部安全距离 |
| 入口与文案 | 原型“继续学习”和演示导航 | 新用户“开始诊断”，有记录后“继续学习”；标题“学习概览”；不添加英文眉题、演示状态与虚构账号 |

以上是针对正式业务系统的明确适配，不把原型模拟数据当作视觉一致性的目标。

## 第二轮：诊断与导师工作台

`diagnose/page.tsx` 将设置放在答题任务之后；主知识点始终可见，难度、先修深度和题源放入可展开信息，依据异常与仅练习警告继续直接显示。选项整行保留原生单选输入与键盘行为，采用字母框、选中边线和明确的对错文字。预留反馈文字位置，浏览器验证提交前后所有选项行的位置与高度一致。沿用现有 GSAP 进度和答案/证据递进反馈，不改变判分、UUID 或证据权重。

`tutor/page.tsx` 与样式将教材和对话分别放在两个纸面区域；增加阅读行高、段落间距和来源标记。保留实际教材、上传资料、设置和三档帮助。`mini-markdown.tsx` 为导师正文引用增加真正的按钮语义，直接打开原文栏，不再通过拦截路径链接实现；通用引用链接默认行为保持不变。流式等待和正文光标采用静态提示，避免持续闪烁。`layout.tsx` 为支持的移动浏览器设置 `interactive-widget=resizes-content`。

对照检查了主标题、题干与选项比例、实际资料段落、引用标记、两栏留白、手机输入区。正式系统保留学情辅助栏、完整题源警告、多行输入和学习设置；原型中的单条固定问题与固定答复没有迁入。

检查：typecheck、lint、2064 项单测、生产构建通过；286 项学习流程、36 项账号、18 项 MCP 通过。额外检查 390×600 的较小窗口，输入框底部约 483px、底部导航顶部 533px，可继续输入；这是浏览器视口缩小测试，并非实体手机键盘测试。

## 第三轮：路径工作区与最终验收

`path/page.tsx` 将真实下一步任务置于预算之前，合并时间、图谱显隐和章节入口，学习清单位于证据与高级调整之前。章节采用现有 Radix 抽屉，避免手机弹出区域溢出；可滚动、可键盘访问，Escape 关闭并恢复触发点焦点。

`learning-graph.tsx` 在同一工作区展示由 `displayed` 得到的实际学习顺序，点击步骤同步选中节点与推荐理由；增加预算时，真实新增步骤同时在节点和清单中标注。保留 React Flow 的受控节点测量、先修边、缩放与键盘操作；GSAP 继续负责完整学习清单的重排。节点使用纸面与语义色边线，暂缓虚线和阻塞方形标识继续保留。输入、算法路径和手动顺序指纹仍在可展开技术区域。

对照再次检查了原型与最终 1440×960 / 390×960 截图的标题、颜色、表面、间距、图谱与详情布局、顺序标识、手机主操作、引用和输入区。修复了桌面图谱被上方控件挤出首屏的问题；手机保留“先任务、后设置、清单优先”的实际工作流，没有复制原型里默认显示的模拟 Canvas 图谱。实际图谱始终是 React Flow。

### 范围与限制

- 保留真实品牌图标、现有顶栏、完整业务入口与五套主题；不复制原型中的英文眉题、演示账号、固定题目、模拟周学习时长或固定导师回复。上述适配已在逐项对照中说明，按这一正式系统适配方案核对了实际渲染。
- 不增加整套 shadcn/Ant Design/Mantine 或第二个动画引擎；现有 Radix 已覆盖本轮需要的抽屉、命令菜单等交互。
- 背景可见性使用浏览器事件模拟验证；实体低端手机的耗电、GPU 开销、真实后台标签调度和虚拟键盘行为**未实测**。CPU 降速、较小视口与 DPR 测试不能替代真机；手册允许对无法实测的项目明确标注。
- 没有调用收费真实模型；模型侧闭环使用本机 mock，检索、认证、题库判分与真实 API 逻辑照常执行。
- 本地 `AGENTS.md` 保留且被 `.gitignore` 排除；作品文档、生成脚本与视频的原有未提交工作保持原状。
