# 自适应学习路径 V3 实施与验收

设计依据为用户提供的《官方推荐对照_UI视觉改造与Canvas应用手册》和《自适应学习路径_V3交互原型》，从 `D:/夸克` 读取，基于 `2fe08f1` 分三轮实施。原型中的课程进度、题目和回复是模拟数据，正式页面继续使用当前学情、题库与导师接口。

## 设计系统与适配

- 主区以纸张表面、克制的阴影和 16–18px 圆角区分工作区域。暖砂浅色的页面底、纸面、正文与主色对应原型的 `#f7f4ef`、`#fffefa`、`#292721`、`#a14c28`；所有其他配色继续由既有主题变量驱动。
- 标题 26–30px，主任务 27–36px，正文 14–16px，说明 12px；主间距 22–32px，触控入口至少 44px。
- 首页采用约 60:40 主任务与进度布局。Canvas 只有固定关系纹样，不承担业务图谱、文字、输入与点击。
- 桌面保留现有顶栏，而非替换成原型的 238px 侧栏；这是手册明确允许的适配。手机底部提供概览、诊断、路径、导师四个真实路由，顶部保留搜索、更多工具与账号入口。
- 继续复用现有 Radix Dialog/Tooltip、命令菜单、GSAP、React Flow；没有为了组件名称安装第二套主题或动画框架。新画布是原生 Canvas 2D。

## 第一轮：首页与视觉基础

| 文件 | 改动 |
| --- | --- |
| `src/components/learning-dashboard.tsx` | 主任务优先，真实测评覆盖率与到期复习统计；下一步清单和最近学习按真实记录呈现 |
| `src/components/visual/knowledge-contour-canvas.tsx` | 7 个装饰点与 6 条曲线，缓存静态绘制；一个标记沿曲线移动；约 30fps；DPR≤2；离屏、后台、减少动态效果及低算力/节省流量环境采用暂停或静态降级；卸载清理观察器与监听 |
| `app/globals.css` | 主题映射、纸张层级、首页构图、任务卡、课程卡片、手机底部导航与安全区 |

| `src/components/nav-links.tsx`、`ui.tsx`、`icons.tsx` | 新增手机四入口；保留顶栏的工具与认证功能 |
| `scripts/visual-canvas-smoke.ts`、`learning-smoke.ts` | Canvas 无障碍、采样率、减少动态效果、离屏暂停和 CPU 降速实测；更新真实首页身份断言 |

检查：`npm run verify`、`npm run lint -- --quiet`、`npm run build` 通过；105 个单测文件 / 2064 项通过；浏览器学习流程 284 项、认证 36 项、MCP 18 项通过。

Canvas 在 Chromium 6 倍 CPU 降速的 2 秒窗口绘制 61 帧，采样约 **30.00fps**，单次位图复制 JS 调用最大 **1.60ms**。[原始指标](../screenshots/ui-v3/canvas-performance-round1.json)。这一指标不包含完整 GPU 合成耗时，也不等同于低端手机真机测试。低端手机真机尚未实测；自动化与源码检查分别覆盖可观察行为和后台可见性监听。

## 原型与实际渲染对照

本轮对照同时查看了原型和浏览器截图。截图由 Playwright Chromium 在 1440×960 与 390×960 采集，启用减少动态效果；ego 能读取并操作页面，但截图接口持续报告窗口最小化、视口模拟尺寸也不一致，因此指定尺寸截图采用既有 Playwright。

| 对照点 | 原型 | 实际与处理 |
| --- | --- | --- |
| 主构图 | 主任务约六成、课程进度约四成 | 保持同类比例与第一视口主操作；保留实际顶栏 |
| 色彩与表面 | 暖纸色、轻阴影、柔和边线 | 映射暖砂主题变量；深色及另外四套配色沿用各自语义变量 |
| 文字层级 | 课程任务大标题、较小说明与元信息 | 根据真实知识点名称自然换行；没有照搬“栈与队列”模拟任务 |
| 任务点缀 | 低对比度关系线和少量节点 | 原生 Canvas，前景真实 HTML 按钮；手机降低纹样不透明度 |
| 统计 | 模拟 12/40、3 项、4.3h | 新用户真实 0/40；只显示实有测评、达标与复习记录；不生成学习时长 |
| 手机 | 先任务、后进度，底部四入口 | 同样顺序；正文与输入保留底部安全距离 |
| 入口与文案 | 原型“继续学习”和演示导航 | 新用户“开始诊断”，有记录后“继续学习”；标题“学习概览”；不添加英文眉题、演示状态与虚构账号 |

以上是针对正式业务系统的明确适配，不把原型模拟数据当作视觉一致性的目标。
