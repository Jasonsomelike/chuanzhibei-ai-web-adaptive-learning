# 自适应学习路径改进与验收（2026-11-04）

参考：[自适应学习路径项目源码审计与改进建议](https://chatgpt.com/share/6aea9633-e900-83e9-98ab-aaf9212b367e)。以下是当前工作树的实现与本机实测，不代表已经部署或通过远端 CI。

## 已落实的改进

| 参考意见 / 实际问题 | 当前行为 | 主要实现 |
| --- | --- | --- |
| Agent 使用模型自报掌握度或默认先验 | 服务端按会话读取课程与进度，用题库和已选选项重算难度、对错、权重、去重后的掌握度；忽略客户端 α/β。首轮模型请求已包含学情与检索结果，不依赖模型主动查工具 | `learningContext.ts`、`api/agent`、`api/progress` |
| Agent 与当前课程脱节 | 请求携带内置学科或 `directionId`；方向权限在服务端校验。工具绑定当前目标，拒绝跨科参数与自报 mastery；公开 MCP 继续提供独立模拟接口 | `agentContracts.ts`、`learningContext.ts` |
| 普通导师与 Agent 依据不同 | 共用导师人格、语气、教学方式和课程资料来源选择；Agent 可检索当前账号上传原文、内置教材与题库。服务端实际采用的上传片段随 done 回传，界面核对同一份原文与引用编号 | `tutorPreferences.ts`、`tutorPersona.ts`、`tutor/page.tsx` |
| 未测评被说成薄弱 | 普通问答明确标为未知；Agent 返回 unobserved / insufficient / needs_review / likely_mastered，零证据不返回伪装成测量结果的均值；路径界面隐藏零证据的先验百分比 | `learningContext.ts`、`tutor-logic.ts`、`path/page.tsx` |
| 重测删除历史 | 旧作答标记 retired 并保留，本轮重新计证据；稳定 attemptId 随记录保留，真实答题入口生成 UUID | `learner.ts`、`diagnose/page.tsx` |
| 看不到练习如何影响计划 | 同一预算下重建最近一次作答前后路径，展示新增 / 移出步骤、前后指纹及作答历史；重测前历史单独标注 | `learningReport.ts`、`learning-evidence.tsx` |
| 首页技术介绍挤占学习入口 | 首屏改为真实个人进度、复习卡数量、可调整时间的计划预览；课程卡可直接进入诊断，技术说明按需展开 | `page.tsx`、`learning-dashboard.tsx` |
| 路径与导师操作分散 | 路径首屏突出下一步，设置与反事实收进调整面板；学习任务可带问题进入导师且不自动发送；导师桌面材料 / 对话并排，移动端优先对话，输入区保持可用 | `path/page.tsx`、`tutor/page.tsx` |
| 需要教学约束 | 三档帮助：给提示、引导步骤、完整讲解。普通模型和 Agent 共用策略；无模型时前两档明确提供通用引导，不泄露完整检索答案 | `tutorPreferences.ts`、`tutor/page.tsx` |
| 语气设置没有生效 | 发送时读取已保存语气；浏览器测试从设置页选择“严格”，确认真实代理请求包含相应 system 规则 | `tutorPreferences.ts`、`learning-smoke.ts` |
| 多设备进度相互覆盖 | 复用 updated_at 作为 revision，原子条件更新；过期版本返回 409。客户端串行写、合并稳定 ID 的证据并重试；登录时保留未上传记录，失败保留本地副本 | `progressClient.ts`、`api/progress`、`useLearner.ts` |
| 本地知识库修改被远端覆盖 | pendingSync 保存在 IndexedDB；读取保留待同步内容、网络恢复重试，冲突明确提示。按文档选择整份片段，避免新旧正文混合；本地替换文档会删除旧切块 | `kbRemote.ts`、`kbLocal.ts` |
| 知识库 CAS 检查有并发窗口 | 文档 upsert 增加版本条件，两个同版本提交仅一位成功；失败者不继续写片段 | `kbServer.ts`、`db.ts` |
| 切方向与切账号出现旧数据 | 取消过时方向请求、URL 与选择同步；账号清理完成前暂停读取，删除被阻塞时保持本地隔离标记；旧存储实例在换号后失效；普通导师也使用统一进度 hook | `subject.tsx`、`authStore.ts`、`kbLocal.ts`、`kbRemote.ts` |
| 方向写入口缺少一致的边界 | 创建、修改、删除方向以及写题目均检查同源；方向、题目、进度在 JSON 解析前限制请求体 | `api/directions`、`bodyLimit.ts` |
| 移动导航与失败状态 | 次要导航收进更多菜单，核心入口保留；添加可恢复的错误页与品牌一致的 404 | `nav-links.tsx`、`error.tsx`、`not-found.tsx` |

保留了原有 DAG、Beta 后验、确定性排序和路径指纹算法；没有为了显示多个 Agent 而引入额外编排框架。

## 可复现的检查

```bash
npm run verify
npm run lint
npm run eval:rag:hard
npm run build
npm run test:e2e
```

`test:e2e` 自动启动生产构建的本机隔离服务，强制 `DATABASE_URL` 为空、生成临时加密主密钥，只允许指定本机 mock 端口，测试后关闭自己的服务。不要对线上服务运行测试账号脚本。默认端口 3218 / 3219，可通过 `ALP_E2E_PORT` / `ALP_E2E_MOCK_PORT` 更改。

## 新增片段级检索评测

`eval:rag:hard` 使用 22 个手工标注查询、18 个教材 / 讲义片段，包含指针约定、否定问法、流程迁移、近邻干扰与无答案问题。它是小规模回归集，标签未经过独立教师复核。

| 实验臂 | recall@3 | recall@20 | nDCG@10 | 无答案空检索率 |
| --- | --- | --- | --- | --- |
| 无检索 | 0.000 | 0.000 | 0.000 | 1.000 |
| 默认 BM25 | 1.000 | 1.000 | 0.955 | 0.250 |
| 标题加权（仅实验） | 1.000 | 1.000 | 0.955 | 0.250 |

标题加权相对默认的配对 bootstrap nDCG 差值为 0.000，95% 区间 [0.000, 0.000]，因此没有更改生产排序参数。向量 / RRF 臂未测。无答案问题仍可能返回相关片段，检索命中不等于可回答，不能据这些结果宣称学习效果提升。

## 当前边界

- “服务端校验”表示按题库检查选项并重算，不是监考；客户端选择本身仍是学习者自报。
- 没有 selectedIndex 的旧作答保留为归档历史，不再作为可核对的当前证据，需要重新测评。
- 重测归档是按知识点分轮的轻量实现，尚未引入完整 assessment session 表或长期学习效果实验。
- KB 文档的版本争用已修复；文档和片段仍不是同一数据库事务，删除仍缺跨设备 tombstone，尚不支持协同编辑。
- Agent 使用服务端已同步资料和内置教材；单次扫描前 2000 个上传片段，达到上限时明确提示。纯本机笔记、尚未上传的资料、浏览器向量召回与联网结果没有完全迁移到服务端 Agent。普通导师保留这些能力。
- Anthropic 仍不启用工具循环；第三方 MCP、真实 TTS、真实 Neon / pgvector、多浏览器与真实模型的教学质量没有在本轮重测。
- 仍无全站分布式限流；ESLint 无错误，但保留部分已有的 hook 同步警告。

教师管理台、新学科专家审题、真实学生小规模验证与完整向量消融实验属于后续产品与研究扩展。本轮没有修改部署、数据库或比赛提交材料。
